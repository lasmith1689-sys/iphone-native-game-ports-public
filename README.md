# Native iPhone game ports

Dedicated project for native ARM64 iPhone research on Call of Duty (2003), Batman: Arkham Asylum GOTY, Middle-earth: Shadow of Mordor (2014), and Sleeping Dogs Definitive Edition.

**No complete game app or installable game IPA is available yet.** Component builds and Simulator fixtures do not establish gameplay or physical-device readiness.

The approach is static recovery and ahead-of-time native reconstruction. PC streaming and runtime x86 interpretation are outside this project.

Current builds:

- [Encrypted CoD host SDK build](https://github.com/lasmith1689-sys/iphone-native-game-ports-public/actions/runs/40741607802): 5,188 recovered native entries; source and returned diagnostics travel as authenticated ciphertext. This run does not execute a game.
- [Graphics v6 iPhone SDK verification](https://github.com/lasmith1689-sys/iphone-native-game-ports-public/actions/runs/40741821305): native UIKit/EAGL bridge and pinned MIT GL4ES, including indexed draws and two bounded scalar capability queries.
- [Graphics v6 Simulator execution](https://github.com/lasmith1689-sys/iphone-native-game-ports-public/actions/runs/40744937809): 86 calls, eight expected rejections, both scalar queries matched the actual backend, and all 16,384 pixels matched across four self-authored frames. The earlier run 40741839590 timed out; the revised bounded report-file transport completed normally. This is component execution on Apple Software Renderer.
- [External payload ownership SDK and Mac execution](https://github.com/lasmith1689-sys/iphone-native-game-ports-public/actions/runs/40749274279): six actual pthread/mmap cases, including four owners, OS-exit cleanup, external mapping lifetime and allocation/cleanup/retirement failure retention. The unsigned iPhone library is 67,112 bytes. Source engine FLS integration remains incomplete.
- [Graphics v7 iPhone SDK verification](https://github.com/lasmith1689-sys/iphone-native-game-ports-public/actions/runs/40749329080): adds a bounded binary64 depth-clear binding. [Simulator attempt 2](https://github.com/lasmith1689-sys/iphone-native-game-ports-public/actions/runs/40749357470/attempts/2) passed all 24,576 pixels across six frames and all three actual depth references. The first attempt timed out during test-app installation before app execution; that failure is preserved.

- [Graphics ABI8 iPhone SDK verification](https://github.com/lasmith1689-sys/iphone-native-game-ports-public/actions/runs/40754517283): four bounded lighting bindings bring the bridge to 42 APIs. [Simulator execution](https://github.com/lasmith1689-sys/iphone-native-game-ports-public/actions/runs/40756512046) passed 191 calls, 12 expected rejections, typed state and copied-vector checks, and all 40,960 pixels across ten frames with zero error. The earlier fixture compilation failure and its two-enum correction remain preserved. This is Apple Software Renderer component execution.
- [Single-owner heap/key join on Mac ARM64 and iPhone SDK](https://github.com/lasmith1689-sys/iphone-native-game-ports-public/actions/runs/40756982699): seven isolated actual native cases verify checked region retirement, real OS-exit delivery, callback reentry rejection and retained failures. The unsigned iPhone library is 69,336 bytes. Original engine FLS/locale destruction remains incomplete.
- [UIKit foreground provider, attempt 2](https://github.com/lasmith1689-sys/iphone-native-game-ports-public/actions/runs/40757274042/attempts/2): actual iPhone SDK link and all 25 ordered Simulator checks passed, including two real input polls, a measured 503.9 ms main-request timeout, late canceled-work retirement and nonblocking close. The first attempt's report-retrieval timeout is preserved. This uses a recording consumer without recovered engine code, touch injection, game assets or physical-phone execution.

- [Graphics ABI9 iPhone SDK verification](https://github.com/lasmith1689-sys/iphone-native-game-ports-public/actions/runs/40780887655): three bounded default-state setters bring the bridge to 45 APIs; all 69 archive objects link. The [v9c Simulator run](https://github.com/lasmith1689-sys/iphone-native-game-ports-public/actions/runs/40782587335) passed build and signature checks but failed on a native default-state seed GL error. No final state/pixel pass is claimed for ABI9; diagnosis continues.
- [Encrypted loading-host v12 iPhone SDK build](https://github.com/lasmith1689-sys/iphone-native-game-ports-public/actions/runs/40783598850): independent local readback matches all 126 archive objects and verifies 5,188 recovered entries plus 36 host/loading functions as strong file-backed ARM64 code. The unsigned library is 109,825,136 bytes. This compile-only run does not execute engine startup, UIKit services or a game. Native whole-engine stack safety remains unproved.
- [Encrypted renderer command-leaf test](https://github.com/lasmith1689-sys/iphone-native-game-ports-public/actions/runs/40784273426): the bounded recovered command writer matched 128 original-code oracle vectors on native Mac ARM64, with both no-op and unknown-call negative controls behaving as required. The overall run failed its final iPhone import audit on a compiler checked-copy helper; that audit is being reviewed. This does not prove renderer resources, backend execution or physical-phone gameplay.

Public platform fixtures and transport tooling use isolated branches. Recovered source is encrypted. Retail assets, saves and Apple signing keys are excluded. The build key belongs only to this repository; this project is separate from GoWPad.
