# Encrypted CoD physical-target object collection

This job compiles the same 193 recovered-source payloads and 134 selected
translation units as the authenticated Mac v2 collection, using the existing
collector's explicit arm64-apple-ios26.0 / iphoneos target. Only the encrypted
driver target, evidence phase and public context pins differ. It never links,
loads, installs or runs a game or produced object. No certificate is generated.

Recovered source, private build logs and outputs remain authenticated encrypted
bundles. The public tree contains only the twelve reviewed transport/workflow
support files, a manifest, ciphertext and the fixed workflow. Retail assets,
saves, Apple keys and signing credentials are excluded. Existing one-day output
retention, fixed capture budgets, tool deadlines and uncertain-retirement
omission rules remain unchanged. Any actual compiler failure is retained as a
failed encrypted collection; it is not repaired with a stub or zero metadata.

The Mac object/frame witnesses do not certify this iPhone target. A successful
compile still leaves source/instruction/control-flow/writer/alias/atomic/helper
and final-link verification, UIKit integration, signing and device startup.
Continue in the current thread; no new thread is required.
