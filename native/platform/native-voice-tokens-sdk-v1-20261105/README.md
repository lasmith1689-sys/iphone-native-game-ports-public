This own support fixture joins a new32-bit token pool to the existing real
headless miniaudio voice backend. It acquires32 ordinary,32 positional and13
stream voices, proves token/native identity and stale/foreign refusal, binds
copied own stereoPCM, verifies224 predetermined Float32 frames on a separate
callback thread, then releases the real cohorts. The contexts/backend remain
process-lived under their existing retained lifecycle.

The shared implementation is a new two-directive headless miniaudio TU; it
omits the unrelated worker MP3 helper. The pinned vendor/profile and exact
voice-service C/header bodies are unchanged. No recovered game code, retail
assets, saves, guest FS, Apple credentials or keys are included. Miniaudio
0.11.23 header/license are fetched only from the pinned official commit and
verified by exact byte size/SHA256 before compilation; its license is retained.

Actual ARM64 Mac execution is distinct from four repeated iPhoneOS27.1/min26
objects and one unsigned library. This builds no app/IPA, activates no physical
device and implements no legacy middleware/device/startup gate. Standard Mac
linker ad-hoc signatures, if present, are reported separately from developer
signing. No downloaded program is executed on the Windows host.
