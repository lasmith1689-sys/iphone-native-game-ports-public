# Retained worker counter bridge: genuine SDK build

This closure contains self-authored generic CPU/runtime/clock/worker support
and synthetic tests. No recovered game function, retail asset, save, game
import profile/address table, decryption key or signing identity is included.
Support bodies are copied byte-exact from their local frozen parents. The
CPU header is the generic448-byte generated-runtime interface, not a retail
game source file. Its unused helpers are not admitted by this timing test.

One virtual tick is one integer nanosecond;1GHz is a unit, not hardware
resolution or physical CPU cycles. A real immutable64-byte retained binding
copies the typed provider snapshot and captures current host/pthread. TLS
activation is worker-local. Success required_counter changes only RAX/RDX,
zeroextending both32-bit words. Failure stamps RIP and calls the genuine
nonreturn fault boundary. Soft read/frequency APIs share the same binding.
Lifecycle changes require observed native depth0; outer caller still owns
quiescence/lifetime/faulted-invocation discard. No guest unwind is supplied.

The driver builds each of eight genuine iPhoneOS objects twice and compares
complete bytes and stack-usage records. It requires actual SDK Mach time and
pthread headers, bounds dependency roots, checks the whole export/import
frontier and creates a deterministic archive. Native ARM64 Mac tests use
actual pthreads, retained bindings, real CRT setjmp/fault-discard and both a
controlled synthetic provider and genuine Mach clock. Controlled4104 vectors
and two overlapping workers are separate from real-clock tests. Static frame
reports exclude callees and do not bound full game worker stack demand.

No downloaded executable is run on the Windows PC. Mac test executables may
have normal linker ad-hoc signatures; no Apple development identity or
installable iPhone app is created. SDK success is component evidence, not
game startup, iPhone execution, playable conversion or delivery. Next: join
the exact SDK support artifacts to private generated consumers and finite
native startup. Continue in the current thread; no new thread is needed.
